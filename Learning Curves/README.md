This directory contains 5 experimental result folders. The folder names follow the pattern `4_N_4`, where `N` denotes the number of reflecting elements. Each folder stores the complete experimental data and results for the corresponding parameter setting.

## Folder List

| Folder | Description |
| --- | --- |
| `4_4_4` | Experiment group: results for parameter N = 4 |
| `4_10_4` | Experiment group: results for parameter N = 10 |
| `4_20_4` | Experiment group: results for parameter N = 20 |
| `4_32_4` | Experiment group: results for parameter N = 32 |
| `4_4_4_Grid` | Grid-based (scan) extension of the `4_4_4` |
